OZARK RESOLE
custom illustrations // 2026
Client requested custom illustrations for a climbing shoe resole business. I was given creative freedom to choose an Arkansas animal and given direction to create certain “expressions” which could be paired with their FAQs, shipping, business mission, etc.
THEATER ICONS
illustrations // 2026
This was a class project called Icons for Awareness. I chose to create a set of icons that illustrate the importance of live theater through its own stories. The set was designed to be fun, approachable, and quirky.
FOUND

This project was a personal exploration of collage using found objects. The works were made of random buttons, wood chips, magazine scraps, tissue paper, etc. and explore shape, color, and movement.
